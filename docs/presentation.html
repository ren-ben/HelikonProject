What is Helikon?

A web application that helps teachers create CLIL materials using AI

🎓

CLIL Methodology

Content and Language Integrated Learning — subject teaching in a foreign language, structured by Bloom's Taxonomy

🤖

AI Generation

5-step wizard generates worksheets, quizzes, glossaries and more via cloud LLM APIs

📚

Document Context

Upload your own documents — the AI uses them as context for more relevant, source-based materials

✏️

Rich-Text Editor

📤

Professional Export

Export materials as styled PDFs or HTML files for classroom use

🔐

Multi-User System

Key Differentiators

What Sets Us Apart

Not a ChatGPT wrapper — a specialized tool purpose-built for teachers

1

Bloom's Taxonomy Prompt Engineering

Every material is structured by cognitive levels — remember, understand, apply, analyze, evaluate, create.

Theory

CLIL & Bloom's Taxonomy

The pedagogical foundation behind every generated material

🎓

CLIL

Content and Language Integrated Learning integrates subject matter with a foreign language. Students learn both — the subject content and the language — simultaneously.

Content — subject knowledge
Communication — language skills
Cognition — thinking skills
Culture — intercultural awareness
🧠

Bloom's Taxonomy

Six cognitive levels, from basic recall to creative synthesis. Helikon's prompt engine structures materials across these levels.

Create — design, construct, produce
Evaluate — judge, justify, critique
Analyze — compare, organize, deconstruct
Apply — use, implement, execute
Understand — explain, classify, summarize
Remember — recall, list, define
Theory

What is RAG?

Retrieval-Augmented Generation combines document knowledge with AI generation

💬

Without RAG

LLM generates from training data only. May hallucinate. No grounding in your specific documents.

Generic · Unverifiable · No sources
→
📚

With RAG

Relevant document chunks are retrieved and injected as context. LLM answers grounded in real sources.

Grounded · Cited · Verifiable

Architecture — Layer 2

Reverse Proxy

TLS termination, routing, and security hardening

:80 / :443 🔀

Nginx + Caddy

Reverse Proxy · TLS · Rate Limiting
  • / → Vue static files (built at deploy)
  • /api/** → Spring Boot backend
  • Rate limits: auth 5r/m, upload 10r/m
  • Security headers: X-Frame, X-Content-Type, Referrer-Policy
  • Let's Encrypt TLS certificates via Caddy
